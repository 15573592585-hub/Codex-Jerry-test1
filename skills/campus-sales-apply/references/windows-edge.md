# Windows招聘网页操作说明

适用于用户授权控制的本机招聘浏览器。简历使用工作约定中的定稿PDF，不进入可画或其他排版工具。先读取实际窗口、Document、控件名称和类型，不照抄坐标、职位ID或控件ID。

## UIAutomation与输入

通过PowerShell的UIAutomationClient/UIAutomationTypes按进程和窗口标题确定目标，必要时限定招聘页面Document。原生操作前核验前台PID，UIA与鼠标坐标使用同一DPI上下文。同名控件按类型与所属字段限定。

只在前台不属于目标应用时激活，不要每次都重新最大化：这会关闭菜单或改变滚动位置。下拉框打开、搜索、选择尽量在一段执行中完成，开始新字段前可Esc关闭旧菜单。

`IsOffscreen=false`不保证目标未被固定页脚遮挡。正文控件滚到可见中部再点；固定底部按钮不能通过滚动移动。有InvokePattern的按钮可直接调用并核对实际后续界面。

中文输入法下逐字符SendKeys可能丢数字或重排文本。聚焦唯一可编辑框后，用Unicode剪贴板一次粘贴，明确发送Ctrl按下、字母按下/抬起、Ctrl抬起事件；重新读取并逐字核验。尽量恢复原剪贴板，不记录其内容。值不一致时先修正，不带错继续。

## Edge网申

- 每家公司或招聘站点都新建独立标签页。打开前记录已有标签页，禁止复用、导航或关闭邮箱和其他用户标签页。
- 打开真实个人中心核验登录和申请历史，不依赖缓存的“退出”字样。本机Edge登录不会自动同步到TinyFish，不复制Cookie或令牌。
- 日期控件可能同时暴露同名只读展示框和弹出的可编辑框。打开后看ValuePattern.IsReadOnly，填可编辑框，Enter确认，再核对最终日期。
- “是/否”常在多个字段重复。单选限定RadioButton并核验IsSelected，菜单限定ListItem，结合字段标签定位。
- 省市联动可能使用名称为空、class为`ant-select-search__field`的搜索框。仅在已确认的当前下拉内定位可编辑框，搜索并精确选择，检查省和市都已保存。
- 每次操作后重新读取控件，注意页面滚动和重新渲染。保存、提交点击日志不能替代成功结果。
- Moka页面可能暴露多个同名Document，先核对当前地址和实际内容，再定位当前页面文档。下拉框的UIA名称可能仍保留修改前的月份；以旁边可见文字、预览和保存后结果核验，不能只看控件名称。
- 个人信息中的灰色“毕业时间”可能只读并由教育经历派生，应修改教育经历的毕业月份并核对上方同步结果。重新上传PDF可能把月份解析回默认值、清空学历类型；每次解析后重新核验。
- 同企业第二岗位可能默认带入第一岗位附件，必须换成对应岗位PDF。通过申请记录核对实际志愿顺序；不因有修改顺序按钮就擅自调整已有申请。
- 省级面试菜单带右箭头时可能只是父菜单。可先只读核验菜单结构、展开子菜单，不能把父级文字当最终站点。最终异地站点与本人偏好冲突时先确认。
- 招聘隐私条款复选框可能打开带倒计时的说明弹窗，直接点击旁边普通文字或TogglePattern不一定完成勾选。核验真实弹窗确认按钮与返回后的状态。最终提交触发拼图等安全验证时交由本人完成，再查申请记录，不绕过验证或重复提交。
- hotjob.cn常见步骤是保存简历、立即投递、选择志愿/简历、确认提交、查看投递记录。记录不明先查历史，避免重复提交。

这些网页操作方法已在Edge、hotjob.cn和Moka校招申请中验证；其他站点及版本须现场核验，不能宣传为通用免登录自动投递。
